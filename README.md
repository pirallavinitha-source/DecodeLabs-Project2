# Responsive Portfolio Website

A modern and fully responsive personal portfolio website developed using HTML and CSS. This project was created as part of the DecodeLabs Frontend Development Internship Project 02.

## 🚀 Features
- Responsive design for desktop, tablet, and mobile devices
- Modern UI with smooth layout and spacing
- Fixed responsive navigation bar
- About, Education, Skills, Projects, and Contact sections
- Interactive hover effects
- Clean and professional design
- GitHub Pages deployment support

## 🛠 Technologies Used

- HTML5
- CSS3
- Responsive Web Design
- CSS Media Queries

## 📂 Sections Included

- Home
- About Me
- Academic Details
- Skills
- Projects
- Contact
